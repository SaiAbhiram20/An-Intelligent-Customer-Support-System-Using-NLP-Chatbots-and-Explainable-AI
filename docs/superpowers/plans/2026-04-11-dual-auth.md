# Dual Authentication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gate the chat with user credentials and the dashboard with admin credentials, using two independent JWT sessions stored in localStorage.

**Architecture:** A new `/api/user-login` endpoint checks `USER_USERNAME`/`USER_PASSWORD` env vars and issues a `chat_token`. The existing `/api/login` issues `admin_token`. The frontend stores both tokens independently; chat gating checks `chat_token`, dashboard gating checks `admin_token` and shows a modal overlay when missing.

**Tech Stack:** Flask + PyJWT (backend), React 19 + Vite (frontend), localStorage (token persistence)

```python
@app.route('/api/user-login', methods=['POST'])
def user_login():
    data = request.get_json()
    if not data:
        return jsonify({"error": "No credentials provided"}), 400
    username = data.get("username", "")
    password = data.get("password", "")
    if (username == os.environ.get("USER_USERNAME") and
            password == os.environ.get("USER_PASSWORD")):
        token = jwt.encode(
            {"sub": username, "role": "user",
             "exp": datetime.utcnow() + timedelta(hours=8)},
            os.environ["JWT_SECRET_KEY"],
            algorithm="HS256"
        )
        return jsonify({"token": token})
    return jsonify({"error": "Invalid credentials"}), 401
```
